# 市況グラフ・相場システム監査（2026-10-15）

## 結論

履歴データの日付・値の対応がツールチップと過去比較でずれる原因がありました。グラフの期間判定、比較日付、系列の照合方法を修正しました。相場値は資料の裏付けがない限り変更していません。

## 見つかった問題と原因

1. **港ごとのツールチップが別の日の値を並べることがあった。** Chart.js の `index` モードは各データセットの同じ配列番号を対応付けます。港ごとに休場日や水揚げ日が異なり配列の日付が揃わないため、表示日と別日の価格が同じツールチップに出ることがありました。X座標での照合に変え、表示日と各点の実取引日を明示します。

2. **「1か月前」などの比較線が暦日と一致しなかった。** 1か月を30日、3か月を91日、半年を182日、1年を365日として扱っていました。月長やうるう年によって比較線のX位置がずれます。比較基準日から暦月で過去日を求め、その基準日間の日数で比較線を現在の軸に重ねます。

3. **期間フィルターが未来日を含み、日境界も時刻に左右された。** 旧条件は「何日前かが上限以下」だけで、負の日数（未来日）を除外していませんでした。また日付のみの値を時刻付きで比較し、端の日が閲覧時刻によって変わりました。市場日（日本時間）の日付キーで始点・終点を判定し、未来日を除外します。

4. **有効な港名や価格・数量が欠けたCSV行が105件あった。** 2026-06-11 のCSV変更（commit `5155914c`）で、文字化けと列ずれのある古い行が有効CSVへ入りました。従来の再生成処理は価格か数量が空なら黙って読み飛ばしていました。105件は既存の正規データと日付・港・価格・数量が重なる行で、グラフJSONへの反映はありませんでした。正規行を残してこの105件を現行CSVから除き、再生成処理が不正行を検出して停止するようにしました。過去のバックアップは変更していません。

5. **山川の2026-05-11データが5サイズで二重登録されていた。** 5件とも同じ日・サイズ・船名・価格・数量の完全重複でした。Git履歴では1件目の重複が `4bc822d4`、残りの再登録が `5155914c` に入っています。以前の検証は焼津の同日重複だけを確認していたため検出できませんでした。各サイズを1件にし、完全重複を全港で検出するようにしました。
